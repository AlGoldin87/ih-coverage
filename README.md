# ih-coverage: Intelligent Discretization Tuning

`ih-coverage` — это не просто набор функций для дискретизации. Это **инструмент для исследования данных**, который помогает найти идеальный баланс между детализацией и надёжностью. Библиотека реализует **Критерий Информационной Сложности (Information Complexity Criterion, ICC)** — математически обоснованный подход к выбору оптимальной резкости (`sharpness`).

## Философия: IH-EDA

Эта библиотека воплощает идею **Information-Theoretic Exploratory Data Analysis** — исследования данных с помощью теории информации. Мы не просто готовим данные для модели. Мы задаём вопрос: «Какой масштаб взгляда на признак X позволит увидеть его истинную структуру, не потеряв важных деталей и не утонув в шуме?».

## Три инструмента исследователя

### 1. `discretize` — Применить резкость

**Назначение:** Быстро превратить количественный признак в набор интервалов с заданной резкостью.

**Сигнатура:** `discretize(data, sharpness)`
- `data` (np.ndarray, float32): Данные формы `(n_samples, n_features)`.
- `sharpness` (float): Параметр резкости (число интервалов ≈ `2 / sharpness`).
- **Возвращает:** Матрицу `int32` — имена интервалов для каждого значения.

### 2. `check_coverage` — Проверить результат

**Назначение:** Провести детальную диагностику. Показать, какие интервалы наполнены хорошо (✅), а какие — потенциально ненадёжны (⚠️).

**Сигнатура:** `check_coverage(data, sharpness, min_per_interval, feature_indices)`
- `data` (np.ndarray, float32): Исходные данные.
- `sharpness` (float): Проверяемая резкость.
- `min_per_interval` (int): Порог для предупреждений (по умолчанию 5).
- `feature_indices` (list[int]): Какие столбцы проверять.
- **Возвращает:** Полный отчёт (словарь) с рекомендациями по каждому признаку.

### 3. `suggest_sharpness` — Найти идеал

**Назначение:** Сердце библиотеки. Найти оптимальную резкость для **одного признака**, которая минимизирует **Критерий Информационной Сложности (ICC)**.

**Сигнатура:** `suggest_sharpness(column, min_per_interval=5, alpha=1.0)`
- `column` (np.ndarray, float32): Одномерный массив значений признака.
- `min_per_interval` (int): Ориентир по минимальной наполненности.
- `alpha` (float): Коэффициент баланса в формуле ICC.
- **Возвращает:** `float` — оптимальное значение `sharpness`.

## Критерий Информационной Сложности (ICC)

Математическое ядро, которое управляет поиском. ICC выбирает алфавит (разбиение), минимизируя сумму двух потерь:

**ICC(K) = (H_ref - H_current) + Σₖ (α / countₖ)**

- **H_ref - H_current (Плата за огрубление):** Разность энтропий между эталонной (максимально детальной) и текущей дискретизацией. Сколько деталей мы потеряли, укрупняя интервалы.
- **Σₖ (α / countₖ) (Плата за ненадёжность):** Интегральный штраф за каждый интервал, обратно пропорциональный числу наблюдений в нём. Чем меньше данных в интервале, тем дороже мы платим за доверие к нему.

Эта формула не допускает ни чрезмерной детализации (когда интервалы пустые), ни чрезмерного огрубления (когда важные различия стираются). Это и есть **золотая середина** между потерей информации и статистической надёжностью.

## Экосистема IH-анализа

- **[`ih-prep`](https://github.com/AlGoldin87/ih-prep)** — Подготовка данных. Принимает DataFrame и словарь резкостей (`sharpness_map`), возвращает итоговую матрицу имён для анализа.
- **[`ih-lib`](https://github.com/AlGoldin87/ih-lib)** — Вычислительное ядро. Энтропия, взаимная информация, мера связи R(Y|X).
